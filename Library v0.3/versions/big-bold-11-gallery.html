The framework

Four moments

A pattern lives inside one of four moments in an AI experience. Each stage opens a different design conversation, so the right pattern is always one click away.

Categories

Every stage opens onto a tighter set of design problems.

Inside each stage, patterns cluster around a handful of recurring conversations the team should have together. What the AI is, how the user enters, how the system responds, what changes over time.

Onboarding1

What the AI is, and what it can do.

Orientation before real use. Get this right and trust compounds across every later phase.

Trust & disclosureWhat is this, what are the rules, what data does it use.
IdentityWho the AI is: visually, verbally, behaviourally.
Capability discoveryShowing, not telling, what the system can actually do.
