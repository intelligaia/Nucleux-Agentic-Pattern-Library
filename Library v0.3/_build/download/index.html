nucleUX home concept

The concept home page as one HTML file, with the live Playground and the "With nucleUX" comparison built from the real @nucleux/react components. It opens in any browser on any computer, with no install or server.

nucleUX-home-concept.htmlHTML · 10.4 MB

After downloading

  1. Double-click nucleUX-home-concept.html. It opens in your default browser (Chrome, Safari, Edge or Firefox).
  2. Use the Pattern library | nucleUX Playground pill at the top to try the Playground.

Good to know

  • Fonts load from the web; offline, the page still works with system fonts.
  • Everything stays on this one page: the nav is there to look at, and its links don't go anywhere. The full Library, Docs and MCP pages are at nucleux.in.
  • The Playground picks patterns with its built-in rules; the AI planner runs only on nucleux.in.
